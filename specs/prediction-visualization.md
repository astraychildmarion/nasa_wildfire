# Prediction visualization

- The 1–7 day forecast is a donut with one equal segment per local forecast day.
- Segment colour encodes regional mean Fire Detection Probability using fixed percentage bands.
- Each day remains labelled with date, probability, and anomaly ratio; missing values are not
  treated as zero.
- The Prediction page displays the active AOI centre and identifies the California fallback.
- Historical monthly activity uses a data-driven Y-axis with 8% padding instead of forcing zero.
